Tic-Tac-Toe (2 Player)

📌 Overview

This is a simple browser-based Tic-Tac-Toe game for two human players.
Built using HTML, CSS, and JavaScript, it allows two users to take turns playing on the same device in a clean, responsive interface.
🛠️ Technologies Used

    HTML5 for structure and layout

    CSS3 for styling and responsive design

    JavaScript for game logic, player turns, and win detection

📂 Project Structure

text

🚀 How to Run

    Clone or download the repository to your local machine.

    Open the TicTacToe.html file in any modern web browser (Chrome, Firefox, Edge, etc.).

    Play the game directly in the browser.

✨ Features

    Two-player game on the same device (no AI opponent)

    Alternating turns between Player O and Player X

    Highlight and disable selected cells

    Detects game winner or draw

    Reset and New Game buttons to replay

🎮 How to Play

    Players take turns clicking empty boxes to place their mark (O or X).

    The first player to align three marks horizontally, vertically, or diagonally wins.

    If all boxes fill with no winner, the game ends in a draw.

    Use the Reset button to clear the board or New Game to start fresh.

📝 Notes

    This project is purely client-side and does not use any backend.

    The UI is simple and designed for learning basic JavaScript game logic and responsive CSS.
